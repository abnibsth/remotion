# Chaos to Order

20s / 1200-frame vertical Remotion composition `ChaosToOrder`; prototype `ChaosToOrderPrototype` is 8s /480 frames. 245 original seeded objects transition from chaos to modular grid to depth-compensated ORDER silhouette and return through a continuous periodic loop.

- `objects.json`: final-silhouette-first object assignments generated by `scripts/chaos-to-order/design.py` from installed Space Grotesk Bold.
- `motion.ts`: pure absolute-time paths, periodic chaos, perspective camera and projection.
- `film.ts`: depth-sorted SVG drawing and minimal editorial typography.
- `index.tsx`: Remotion wrapper and original soundtrack.

`npm run chaos:style`, `chaos:prototype`, then `chaos:render`. `chaos:test` covers geometry and loop derivatives. `chaos:verify` checks outputs, browser playback and rendered loop equality. `chaos:seek` exposes http://127.0.0.1:3103 and `await window.seek(seconds)`.

Notes and QC: `scripts/chaos-to-order/`. Deliverables: `out/chaos-to-order/`. Perspective is explicit analytic 2.5D billboards with XYZ depth, not a full solid-mesh scene. ORDER consists of the same fragments, not a text-overlay replacement. Audio is original synthesis with a short silent loop seam, no narration.
