# HTTP/3

**HTTP/3** is a major revision of the [HTTP network protocol](https://developer.mozilla.org/en-US/docs/Web/HTTP), succeeding [HTTP/2](https://developer.mozilla.org/en-US/docs/Glossary/HTTP_2).

The most notable difference in HTTP/3 is that it uses a protocol named [QUIC](https://developer.mozilla.org/en-US/docs/Glossary/QUIC) over [UDP](https://developer.mozilla.org/en-US/docs/Glossary/UDP) instead of [TCP](https://developer.mozilla.org/en-US/docs/Glossary/TCP).
This reduces [latency](https://developer.mozilla.org/en-US/docs/Glossary/Latency) and eliminates the [head-of-line blocking](https://developer.mozilla.org/en-US/docs/Glossary/Head_of_line_blocking) problem in HTTP.
